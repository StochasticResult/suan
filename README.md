# 玄学排盘助手

一个面向中文用户的网页排盘工具，集成六爻、奇门遁甲与八字排盘。项目是纯静态网页，不需要后端，适合直接部署到 GitHub Pages 或本地打开使用。

## 在线访问

[https://stochasticresult.github.io/suan/](https://stochasticresult.github.io/suan/)

## 功能概览

### 六爻排盘

- 支持传统三枚钱币起卦：按初爻到上爻逐爻输入，每爻记录三枚钱币的真实结果。
- 支持数字起卦：保留两数字起卦，以及“仅数字 / 数字 + 时辰”动爻模式。
- 展示本卦、变卦、互卦、综卦、错卦。
- 展示周易卦名、卦辞、动爻爻辞。
- 专业盘信息包含六神、纳甲、六亲、世应、伏神、月建、日辰、旬空。
- 支持一键复制完整六爻盘、导出 JSON、导出排盘图。

### 奇门遁甲

- 支持时家转盘排盘。
- 当前固定口径为：拆补法、节气定阴阳遁、符头定三元、中五寄坤二。
- 展示阴阳遁、局数、上中下元、符头、旬首、旬空、时干入盘、值符、值使。
- 九宫盘面展示八神、九星、八门、天盘干、地盘干。
- 支持一键复制完整奇门盘，复制文本中包含排盘口径，便于复核与分享。

### 八字排盘

- 支持四柱、十神、藏干、纳音、旬空。
- 支持大运、流年、流月、流日联动查看。
- 八字记录保存在当前浏览器的 `localStorage` 中。

## 时间与时区

六爻、奇门和八字都支持时间基准选择：

- 本机所在时区
- 已是北京时间
- 手动 UTC 偏移

程序会先把输入时间换算为北京时间，再用于节气、干支、奇门起局等计算。这样人在美国或旅行到其它地区时，也可以明确指定输入时间的来源，避免把当地时间误当北京时间。

## 本地运行

这是纯静态网页项目，无需后端服务：

1. 下载或克隆项目。
2. 直接打开 `index.html`。

如果浏览器限制本地文件加载，也可以在项目目录启动一个静态服务，例如：

```bash
python -m http.server 8765
```

然后访问：

```text
http://127.0.0.1:8765/
```

## 技术说明

- 前端：原生 `HTML` / `CSS` / `JavaScript`
- 历法：`lunar-javascript`
- 导图：`html2canvas`
- 数据存储：浏览器 `localStorage`，仅用于八字记录
- 周易文本：`data/iching.json`

## 口径说明

- 六爻钱币法采用传统三枚钱币：字为 2，背为 3；三字为老阴 6，三背为老阳 9。
- 奇门遁甲当前采用固定的时家转盘、拆补法口径，不混用飞盘、置闰、阴盘等其它流派。
- 本项目用于传统文化学习、排盘复核与技术实现演示，不构成现实决策建议。
